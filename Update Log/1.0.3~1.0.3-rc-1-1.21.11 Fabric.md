# Subtitle Highlight Unofficial Reset - 更新日志

## 版本: 1.0.3-1.21.11 Fabric

### 更新日期: 2026-05-27

### 性能优化

1. **颜色配置查询缓存**
   - 在 `SubtitleTypeLoader` 中实现了颜色查询缓存机制
   - 使用 `ConcurrentHashMap` 实现 O(1) 颜色查找
   - 大幅减少重复配置查找的性能开销

### 修复内容

1. **反射方法调用异常修复**
   - 修复 `getTime()` 方法不存在导致的 `NoSuchMethodException` 异常
   - 改用直接字段访问 `field_1472`（startTick 字段）获取字幕开始时间
   - 显著改善字幕渲染性能，解决掉帧问题

### 开发者优化

1. **性能日志系统**
   - 在 `SubtitleEntryMixin` 中添加性能日志功能
   - 记录字幕着色处理的调用次数、平均耗时、最小/最大耗时
   - 便于开发者分析和优化性能瓶颈

### 兼容性

- 与 1.0.3 版本完全兼容
- 无需重新配置，原有配置文件可直接使用

## 版本: 1.0.3-rc-1-1.21.11 Fabric

### 更新日期: 2026-05-30

### 性能优化

1. **移除反射方法调用**
   - 完全移除 `getTime()` 反射方法调用
   - 使用 Mixin 直接访问 `SubtitleEntry` 的 `field_1472` 字段
   - 消除每次渲染的反射查找开销
   - 解决 `NoSuchMethodException` 导致的严重掉帧问题

2. **简化 Mixin 代码**
   - 移除不必要的视锥体检查逻辑
   - 移除 `drawTextWithShadow` 反射调用
   - 提高代码可维护性和执行效率

### 修复内容

1. **ConcurrentHashMap null 值问题**
   - 修复 `SubtitleTypeLoader.getColor()` 中将 null 存入 `ConcurrentHashMap` 导致的 `NullPointerException`
   - 使用 `NULL_MARKER` 标记 null 结果，避免在缓存中存储 null 值
   - **允许客户端在服务端未安装该模组时正常进入服务器**

2. **服务端兼容性**
   - 修复客户端安装模组但服务端未安装时无法进入服务器的问题
   - 确保模组在纯客户端环境下正常工作

### 性能提升

- 字幕渲染性能提升显著
- 消除了之前版本中每次字幕渲染都会抛出的异常
- 游戏帧率稳定性大幅改善

### 兼容性

- 与 1.0.3 版本完全兼容
- 无需重新配置，原有配置文件可直接使用
