# Subtitle Highlight Unofficial Reset - 更新日志

## 版本: 1.0.2-1.21.11 Fabric

### 更新日期: 2026-05-11

### 性能优化

1. **字幕类型匹配算法优化**
   - 将字幕类型匹配从 O(n) 数组遍历优化为 O(1) HashSet 查找
   - 在 `SplitKeyArrays` 类中添加了所有类型的 HashSet 版本（`friendlyMobsSet`、`hostileMobsSet`、`weaponsSet` 等）
   - 修改 `SubtitleEntryMixin`，使用 HashSet 进行快速类型匹配

2. **反射方法调用优化**
   - 在 `SubtitlesHudMixin` 中实现了反射方法缓存机制
   - 缓存 `getTime()` 和 `drawTextWithShadow()` 方法引用
   - 使用双重检查锁定（DCL）确保线程安全
   - 避免每次渲染都进行反射方法查找，显著降低 CPU 开销

3. **代码结构优化**
   - 添加了 `applyColor()` 辅助方法，消除大量重复的颜色设置代码
   - 提取局部变量减少数组访问次数
   - 提高代码可读性和可维护性

### 修复内容

1. **渲染性能问题修复**
   - 可能修复了字幕渲染时导致的掉帧问题
   - 优化了渲染循环中的性能瓶颈

### API 变更

1. **`SplitKeyArrays` 类**
   - 新增公共字段：`friendlyMobsSet`、`neutralMobsSet`、`hostileMobsSet`、`bossMobsSet`、`vehiclesSet`、`projectilesSet`、`explosivesSet`、`decorationsSet`、`hurtSet`、`interactSet`、`workingSet`、`dangerousBlocksSet`、`cropsSet`、`weaponsSet`、`armorsSet`、`toolsSet`
   - 原有的数组字段保持不变，确保向后兼容

### 兼容性

- 与 1.0.1 版本完全兼容
- 无需重新配置，原有配置文件可直接使用
